## 2025-06-24 - [Destructive Action Confirmation]
**Learning:** Destructive actions like deleting a book should always have a confirmation step to prevent accidental data loss. Using an `alertdialog` role and focusing the 'Cancel' button by default enhances both safety and accessibility.
**Action:** Always implement a confirmation flow for irreversible actions, ensuring the UI clearly identifies the target (e.g., the book name) and prioritizes the safe (cancel) option for focus.

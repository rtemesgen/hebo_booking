## 2025-05-14 - Accessible Destructive Confirmations
**Learning:** For destructive actions (like book deletion) in this mobile-first UI, using a dedicated slide-up confirmation sheet is more consistent than native browser alerts. To be fully accessible, these sheets must use `role="alertdialog"`, `aria-modal="true"`, and have an `aria-labelledby` attribute pointing to the title. Additionally, when a sheet is triggered from an options menu, persisting the item's identity in a separate ref (e.g., `bookToDelete`) ensures the UI remains contextually accurate if the menu itself is closed before the confirmation appears.
**Action:** Always implement a dedicated confirmation sheet with proper ARIA attributes for destructive actions, and use specific refs to track the targeted item across the multi-step interaction.
